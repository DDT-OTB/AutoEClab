# 测量数据管理

侧边栏的“数据管理”（`/#data`）保存每次 CV 测量的数据。运行记录用于查看整个自动化流程的动作事件；测量数据用于查看电位、电流、采集结果和具体参数，两者通过运行 ID 和动作 ID 关联。

## 页面

- 按方案、步骤或数据编号搜索，按采集状态筛选并分页查看。
- 点击记录查看 CV（电位—电流）与时间—电流曲线。移动指针查看具体点，使用 SVG 按钮导出当前图形。可切换连线、散点和显示平滑；默认用趋势线配合未平滑散点显示。
- 参数详情同时显示用户输入的实验参数与后端实际下发的 EC110 寄存器值，包括扫描段数和计时换算依据。
- CSV 包含每 100 个 ADC 样本的均值；JSON 包含参数和采集记录；原始 JSONL 保存完整通讯帧，保留全部 ADC 样本。
- 采集中可以查看实时曲线和参数，结束后才开放完整 CSV 和原始帧下载。
- 管理员可在列表或详情点击“删除”，确认记录信息后移至服务器私有回收目录。观测员没有删除按钮，后端也会拒绝观测员请求。采集及文件收尾中的记录不能删除；记录版本变化时必须刷新并重新确认。

## 实时更新

测量工作进程持续接收 CV 的 V2 `0x18` 帧，并将 88 字节公共头与 204 字节采样块分别解码。每个块包含一个有符号 DAC CODE 和 100 个有符号 ADC CODE。

工作进程写入 SQLite 索引、均值 CSV、原始通讯帧，并每约 0.4 秒更新受限大小的曲线快照。0.15.4 起使用均匀覆盖整个采集序列的分桶摘要，合并时保留端点和电位、电流极值，不对“旧抽样点＋新数据”反复等权压缩，避免旧曲线逐渐丢失、前段被错误连成长直线。快照保持有界大小。现有 `/api/events` 状态流推送最新测量记录；页面断线时保留最后曲线并明确显示连接待恢复。

旧版已完成记录的实时缓存若采用旧抽样方式，会在读取时从保留的完整 SQLite 点序列重建显示曲线，随后缓存结果；不会改写 CSV、原始帧或测量元数据。无需重新测量即可恢复已有记录的全程显示。

0.15.5 起默认原始散点显示上限为 3000 点，实际点数由端点、极值去重和数据量决定；不会补造采样点。已保存记录也会从完整数据重新计算显示结果，无需重新测量。

“显示平滑”使用独立于极值散点的趋势数据：后端从完整均值数据按采集索引分桶求均值，桶合并保留样本数与和，且在电位扫描换向处分支，不混合不同扫描分支。前端对各分支进行 7 点显示移动平均，再用控制点受限的三次曲线连接，避免直线逐点连接的折角和插值额外过冲。扫描端点保留，淡色点和悬浮读数仍为未平滑抽样值。透明散点重叠可显得更深，不代表不同类型的数据。

曲线的均值和插值仅用于观察，不是额外实测点。超过 1024 个扫描分支的异常电位序列不生成趋势，仍可查看原始散点和 CSV，避免趋势缓存无界增长。旧实时快照尚无趋势时只显示散点，不从极值抽样点估计趋势。趋势桶的时间坐标取桶中最后一个真实接收时刻；时间图仍保留同帧重复接收时刻，不虚构连续采样时间。SVG 文件名与图标题标注当前显示模式；所有 CSV、原始帧和数值统计保持原样，不能用趋势线代替定量分析或硬件噪声验证。

数据格式中的图形点为 `[index, time_s, potential_v, current_a]`。网页把 A 转为 µA 显示。

## 存储与访问

数据保存于应用的 `data/measurements/`：

```text
index.sqlite3
cv-<random-id>/
  metadata.json
  live.json
  points.csv
  frames.jsonl
```

目录使用 0700，数据库、元数据及采集文件使用 0600。真实数据、校准参数及 SQLite 的 WAL 文件均在被 Git 忽略的 `data/` 内，不随源码发布。

全部列表、详情、曲线、下载和实时推送均要求有效登录。观测员可以查看及下载数据，只有管理员可以通过现有执行接口发起、停止自动化。数据页面不提供任意串口命令或脚本上传入口。

| GET 接口 | 功能 |
| --- | --- |
| `/api/measurements?query=&state=&limit=30&offset=0` | 查询、筛选和分页 |
| `/api/measurements/<id>` | 元数据与图形数据 |
| `/api/measurements/<id>/points?limit=1800` | 指定上限的抽样图形数据 |
| `/api/measurements/<id>/download?format=csv` | 完整均值 CSV |
| `/api/measurements/<id>/download?format=json` | 参数与采集记录 |
| `/api/measurements/<id>/download?format=raw` | 原始通讯帧 |

这些 GET 请求不会打开串口或启动测量。

管理员删除使用 `DELETE /api/measurements/<id>`，请求体仅包含当前 `expected_version`，并要求会话、CSRF 与同源保护。操作写入账号审计及私有回收清单，文件移入 `data/measurements/trash/<deletion-id>/`，SQLite 中保留数据点以便恢复。删除后的记录不再出现在列表、实时快照、详情或下载接口。文件写入锁与数据库事务防止删除正在收尾的数据；归档失败时恢复原位置。此功能不是永久销毁，不自动释放回收数据占用的磁盘空间。

## 数据含义

电位由仪器返回的 DAC CODE 与 DAC 参考电压换算，不是独立的电位传感器读数。电流使用当前灵敏度和 PGA 增益及服务器配置的系数换算；默认系数只产生名义值，不能据此宣称仪器的计量精度。

时间字段是相对于启动应答的服务器接收时间，不是设备逐样本时间戳。USB 缓冲、分包和处理延迟会影响时间轴，不能使用该图直接验证精确扫描速率或采样周期。

异常、中止及未完成全部电位段的测试都保留部分数据，但不会标记为完成。停止应答未确认时会明确标记异常。参数中的目标扫描速率与实际下发计时字段同时保存；`timing_verified=false` 时，界面说明尚未独立校准。
