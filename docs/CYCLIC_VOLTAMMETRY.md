# EC110 循环伏安法

0.14.0 支持在实验方案中配置 CV、通过现有管理员执行流程驱动 EC110、在实验运行的电化学工作站设备详情中实时查看曲线，并在“数据管理”中读取历史结果。公开配置默认不启用工作站；禁用时仍可编辑和保存草稿。

## 使用方式

1. 在“实验方案 → 流程编辑”选择功能块，添加“循环伏安法”动作。
2. 在右侧输入电位上下限、起止电位、方向、目标扫描速率、采样电位间隔、圈数、静置时间、电流量程及参比电极。
3. 使用“校验与预演”查看设备限制和预计时间，保存或载入运行页。
4. 管理员按现有前置准备流程完成回零（使用注射泵时）、排空及现场空池确认。需要测量液体时应在正式流程中安排注液动作，然后执行 CV。
5. 实验运行页点击电化学工作站，在设备详情中切换 CV 与时间—电流曲线；CV 开始时会自动定位到工作站；每个 CV 动作生成独立数据记录，可进入“数据管理”查看或下载。

方案 JSON 继续使用 `device=electrochemical_station`、`operation=measure` 和 `technique=cyclic_voltammetry`。泵阀动作与测量动作按功能块顺序执行，不会跳过不支持的测量。

## 输入参数

| 字段 | 含义 | JSON 单位 |
| --- | --- | --- |
| initial_potential_v | 起始电位 | V |
| upper_potential_v / lower_potential_v | 电位上、下限 | V |
| final_potential_v | 终止电位 | V |
| initial_scan_direction | 先向上限或下限扫描 | positive / negative |
| scan_rate_v_s | 目标扫描速率 | V/s |
| potential_step_v | 采样电位间隔 | V |
| cycles | 完整扫描圈数 | 整数 |
| quiet_time_s | 扫描前静置 | s |
| current_range_a | 固定量程或自动量程 | A；自动为 null |
| reference_electrode | 现场参比电极标识 | 英文标识 |

网页的 mV/s、mV、µA 会转换为上述 JSON 单位。参比电极 `unspecified` 表示没有注明，不表示相对 OCP，也不会自动执行电位基准换算。

CV 电位按仪器协议开放为 -3.0 V 到 +3.0 V，不再使用 ±0.1 V 的人为执行限制。模板默认示例为 ±0.5 V，起止均为 0 V、1 圈、静置 5 秒和自动量程；默认值与允许范围是不同概念，已有方案不会被自动缩小窗口。

## 后端与协议

`ec110.py` 根据提供的 EC-110 对外通信协议 v1.0（2026-10-22）与已验证的 CV 收发格式实现：

- `0x03/0x04` 完成现有固件要求的采集握手并校验 EC110 身份；初始化阶段停止默认 OCP。
- `0x05/0x06` 配置 CV，要求 60 字节请求和 64 字节成功标志加完整回显。
- `0x11/0x12` 控制模式 1；只接受匹配流水号、成功标志与逐字节回显。
- V2 `0x18` 使用 88 字节公共头和 204 字节采样块；公共头为大端，DAC 与 ADC 样本为小端有符号 16 位。
- 一个从窗口内部出发、经过两边界并回到终点的完整循环，使用 3 个扫描段；N 圈使用 `2*N+1` 段。后端按实测返回值核对所有目标电位段后才报告完成。
- 不发送 EIS 的 `0x61` 轮询，也不使用 `0x20` 原始 EIS 数据代替 CV 数据。
- 正常完成、中断、解析错误与存储错误均进入停止清理；即使原始帧日志写入失败，仍尝试发送并校验停止命令。

泵阀与工作站共用原有自动化锁；所有参与泵阀和工作站先预检查，再发生移动。工作站使用串口排他锁与 Linux `TIOCEXCL`，避免运行时被其他程序再次打开。服务器预演、保存方案、状态读取和数据查看均不打开串口。

## 服务器配置

在被忽略的本机 `config/server.json` 中配置 `electrochemical_station`，并同时显式启用总的 `hardware_execution_enabled`。示例文件中的两个开关均为 false。

| 配置项 | 含义 |
| --- | --- |
| enabled / port / baudrate | 工作站启用开关及仅由服务器指定的串口 |
| max_potential_v / max_cycles | 当前已允许执行的电位范围和圈数 |
| max_duration_s / max_raw_bytes | 采集时长与原始记录大小上限 |
| dac_reference_mv | 目标扫描速率换算时使用的名义 DAC 参考值 |
| step_time_unit_ns | 固件计时字段的单位，默认按公开协议使用 1000 ns |
| timing_verified | 计时是否已经独立验证；默认 false |
| zero_i / cal_i / polarity_i / cal_dac | 服务器提供的校准配置；默认仅为名义换算 |

电位允许范围为 ±3.0 V，以 1 mV 为步长；采样电位间隔为 1–64 mV 整数，静置为整数秒，固定电流量程必须选仪器支持档位。完整循环数最多为 499（2*N+1 不超过协议的 1000 段）。未能表示或超出协议范围的参数在启动前被拒绝。服务器另设采集时长与记录大小上限，达到上限时停止并保留部分数据。

目标扫描速率依据配置的 DAC 分辨率和计时单位转换为实际寄存器值。当前固件的计时与公开说明尚未完成独立校核，页面和启动确认明确提示该限制；用户输入、实际下发值和换算依据都会保留。不能把设定速率或服务器接收时间当作已经校准的实际扫描速率。

数据精度、实时图形与下载格式见 [数据管理](DATA_MANAGEMENT.md)。
