# 实验运行与实验方案工作区

侧边栏包含 **实验运行**、**实验方案** 和 **数据管理**。运行页的 CV 曲线位于“电化学工作站”设备状态详情，测量开始时自动定位，不再另占整块独立面板。数据管理通过 `/#data` 查看 CV 测量曲线、参数快照与下载文件。运行记录保持独立入口，账号管理仅管理员可见。小屏幕下使用页面顶部的导航条切换。

## 实验运行

默认进入运行页，也可通过 `/#run` 访问。

1. 在“从方案文件载入”中选择已保存的方案，或点击“导入流程 JSON”载入本机完整流程。支持旧版动作序列和新版功能块实验。
2. 已载入流程显示名称、来源、功能块与动作数量；“查看已载入的动作序列”提供只读摘要。
3. 管理员点击“运行已载入流程”，按方案第一块的执行进度完成按需回零、排空和现场空池确认，然后继续正式实验。运行页不再单独显示回零和排空准备面板。
4. 页面显示实际控制程序的当前动作、进度、装置流程图及逐台设备状态。管理员可请求停止当前实验。

运行页不编辑动作参数。点击“到方案中编辑”可将载入的流程复制到实验方案编辑器；尚未保存的其他草稿会先提示确认。

载入流程只更新本次待运行的副本，不自动启动设备或覆盖文件。没有载入有效流程时不能启动新实验；服务器上已有任务的监测和管理员停止入口仍可使用。完整实验继续受总液量上限、废液流路、回零校验和空池确认规则约束。

## 实验方案

通过侧边栏或 `/#plans` 进入。工作区内部只有两个标签：

- **文件管理**：新建、导入、查询、查看、下载、复制、重命名与删除方案；双击或点击“进入编排编辑”打开流程编辑器。选中文件后也可点击“载入实验运行”。
- **流程编辑**：编辑“实验 → 功能块 → 动作”、管理可复用功能块模板、检查 JSON、预演与保存。底部“载入运行”把当前设计复制到运行页；未保存的有效草稿也可载入。

设备模板入口、原始设备模板 JSON 和设备模板参数区不再显示。泵阀与测量动作仍使用原有系统配置进行校验；可编辑的功能块模板库继续保留，管理员权限和持久化方式见 [功能块说明](FUNCTION_BLOCKS.md)。

## 页面切换与流程副本

- 页面切换和浏览器前进、后退不会重新创建整个应用；设计草稿与已载入的运行流程分别保留。
- 编辑、重命名或删除方案文件不会自动改变已经载入的运行副本。需要运行最新文件时应重新载入。
- 设计页的参数修改不会改变运行页副本；再次点击“载入运行”才会更新待运行内容。
- 运行前确认使用固定的服务器快照。切换工作区不会重置正在进行的确认流程，已有任务仍通过后台事件持续监测。
- 刷新网页或退出登录会清除浏览器内未保存的草稿和载入选择。已保存文件、功能块模板和服务器上的运行任务保持原样；重新登录后可继续监测当前任务。

`/#history` 查看运行记录。页面跳转、加载文件和导入 JSON 不会主动读取串口或发送动作指令；设备状态查询仍需显式点击管理员刷新按钮。
