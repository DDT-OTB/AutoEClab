# 设备状态刷新

管理员点击“刷新全部状态”或设备详情中的“刷新状态”后，后端查询三个蠕动泵、注射泵、切换阀和已启用的电化学工作站。普通页面轮询只读缓存；只读账号不发送串口查询。

- 蠕动泵查询工作状态，切换阀另读取当前通道。
- 注射泵查询状态、设备身份、活塞位置和阀位；错误码如实显示，不自动回零。
- EC110 只发送 `0x03` 并校验 `0x04` 身份应答，显示连接、产品与固件。身份回读不能证明设备空闲，因此显示“已连接”；采集状态由执行控制器与实时数据提供。不复用会发送 OCP 停止命令的测量会话初始化流程。
- 运行与查询共用设备锁；控制器占用时跳过额外查询，使用控制器事件更新。
- 缓存超过 30 秒标记过期；历史曲线明确标记为历史记录，不将旧电位、电流冒充当前读数。
- 串口缺失、无应答、占用和身份异常分别显示。串口节点存在只表示接口存在，不保证仪器有应答。

CH348 转接器使用 ch9344 内核模块。系统更新内核后，需核对模块 vermagic 与当前内核一致，并为新内核重新构建、安装；模块仅存在于旧内核目录时，USB 设备仍能识别，但八路串口与设备别名不会出现。恢复驱动不会发送任何泵阀动作。实际驱动与硬件端口映射属于服务器部署配置，不提交到公共仓库。
